# TaskFlow - Task Management Dashboard

TaskFlow is a responsive task management application
built using HTML, CSS and JavaScript.

It helps users organize daily tasks, manage deadlines,
track productivity and maintain task backups through
an interactive Kanban dashboard.

## Live Demo

https://sachinkumar1712.github.io/taskflow-management-app/

## Features

- Add, edit and delete tasks
- Interactive Kanban board
- Drag and drop task management
- Quick task status updates
- Real-time task search
- Category and priority filters
- Advanced task sorting
- Deadline management
- Overdue and due today indicators
- Progress analytics dashboard
- Dynamic doughnut chart
- Priority distribution charts
- Light and dark mode
- LocalStorage data persistence
- JSON backup and restore
- CSV data export
- Duplicate task prevention during import
- Keyboard shortcuts
- Toast notifications
- Responsive design
- Accessible form controls

## Technologies Used

- HTML5

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/sachinkumar1712/taskflow-management-app.git
```

2. Open the project folder.

```bash
cd taskflow-management-app
```

3. Open index.html in your browser or use VS Code Live Server.

No additional dependencies are required.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| N | Add new task |
| / | Search tasks |
| T | Toggle theme |
| R | Reset filters |
| ? | Show shortcuts |
| Esc | Close modal |

## Data Storage

TaskFlow stores task data and theme preferences in
the browser using localStorage.

Users can export their tasks as JSON or CSV files
and restore task backups using JSON import.
